# Provenance and public boundary

This public product specification was composed by SHPBL, created by Kenneth E. Sweet Jr. SHPBL used its proprietary harvesting and composition capabilities to identify compatible capability intent across CMPSBL, a sister project by the same developer.

The private provenance record locates all selected capability slots and preserves whether each was traced by normalized bytes or by declaration. That private accounting is not an implementation source and is intentionally excluded from this repository.

This repository follows the publication rule: **SHPBL discovers the invention; the public package implements it from a written specification.** No harvested SHPBL or CMPSBL implementation body is included. The behavior specification was authored from product intent and externally observable behavior, not by quoting, translating, structurally reproducing, or mechanically transforming private source.

The MIT grant applies only to the exact files published in this repository. It does not grant rights to SHPBL, CMPSBL, their proprietary engines, private capability bodies, private provenance maps, or any future implementation unless that implementation receives its own explicit grant.
